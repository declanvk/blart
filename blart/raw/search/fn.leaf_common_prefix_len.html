Expand description

Return the number of leading bytes that are equal between the key and the key of a leaf where a optimistic_descent stopped.

The comparison starts from the first unverified byte (or the leaf depth, if nothing was skipped), since all bytes before it are known to be equal.

When nothing was skipped, only the end of the leaf key is left to compare, which is usually short, so it uses short_common_prefix_len. Otherwise the comparison also covers the skipped prefixes, which only happens for prefixes longer than PREFIX_LEN, so it uses the out of line longest_common_prefix_len.

§Panics

  • Panics if the start of the comparison is past the end of either key.
