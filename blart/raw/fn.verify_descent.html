pub(crate) unsafe fn verify_descent<K, V, const PREFIX_LEN: usize, P>(
    root: OpaqueNodePtr<K, V, PREFIX_LEN>,
    key_bytes: &[u8],
    unverified_from: Option<usize>,
    verified_depth: usize,
    leaf_ptr: impl FnOnce() -> NodePtr<PREFIX_LEN, LeafNode<K, V, PREFIX_LEN>>,
) -> Option<SkippedPrefixMismatch<K, V, PREFIX_LEN, P>>
where
    K: AsBytes,
    P: PathTracker<K, V, PREFIX_LEN>,
Expand description

Check the prefix bytes skipped by an optimistic_descent (if any were skipped) up to verified_depth, against the leaf returned by leaf_ptr.

leaf_ptr is only called when bytes were skipped. See verify_skipped_prefixes for the requirements on the leaf and the meaning of the result.

§Safety

  • This function cannot be called concurrently with any mutating operation on root or any child node of root.

§Panics

  • Panics if verified_depth is greater than the length of the key or the leaf key.
