Expand description

The shared search of search_for_insert_point and search_for_prefix_insert_point.

The result is built by on_insert if the key can be inserted, or by on_overwrite if the key is a prefix of existing keys (or an existing key is a prefix of it).

§Safety

  • This function cannot be called concurrently to any writes of the root node or any child node of root. This function will arbitrarily read to any child in the given tree.
