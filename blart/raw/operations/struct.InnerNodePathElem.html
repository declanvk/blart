Expand description

An inner node that the split key passed through, with its children partitioned around the split key.

§Invariants

Let node be the inner node at inner_node_ptr and b be pos.next_key_fragment. The type does not enforce these. collect_split_point_nodes establishes them, split_ancestor preserves them, and InnerNodePathElem::split requires them:

  • Partition: for each child of node at key byte k, if k < b then (k, child) appears exactly once in left_children, and if k > b then it appears exactly once in right_children. The only other entries allowed are at most one entry with key byte b in each vector, which are halves of the path child added by split_ancestor. So every child of node other than the one at b ends up on exactly one side, which is what makes it sound to give each side ownership of its children.
  • Ordering: left_children and right_children are each strictly ascending by key byte.
  • Prefix: for the key bytes that this element was collected with, pos.depth_at_prefix_start + pos.prefix_length < key_bytes.len(). The full prefix of node equals key_bytes[pos.depth_at_prefix_start..][..pos.prefix_length].
  • node is live and has not been modified since the element was collected.

unsafe fn split( self, key_bytes: &[u8], stale_path_slot: Option<u8>, alloc: &impl Allocator, ) -> InnerNodeSplit<K, V, PREFIX_LEN>

Split the inner node into a left side made from left_children and a right side made from right_children.

Each side either reuses the original inner node, becomes a single child, or is a newly allocated inner node. Only one side can reuse the original node, and if neither does, it is deallocated.

stale_path_slot is the key byte of the child on the path, if there is one. The original inner node still has a slot at that key byte pointing to the child as it was before it was split. That pointer is stale, the child may have been reused for one of its halves or deallocated. The halves of the path child (if any) are already in left_children and right_children, so the stale slot must not be copied over if the original node is reused.

§Safety
  • The caller must have exclusive access to the inner node at self.inner_node_ptr and every node in left_children and right_children. No other operation may read or write them for the duration of this function.
  • The inner node must have been allocated with alloc.
  • self must satisfy the InnerNodePathElem invariants, and key_bytes must be the same key bytes that self was collected with.
  • If stale_path_slot is None, left_children and right_children must have no entries at self.pos.next_key_fragment, and the inner node must have no child there. If stale_path_slot is Some(b), then b must equal self.pos.next_key_fragment, and the inner node must have a child at b.
  • Every node in left_children and right_children must be live. The only node allowed to point to them is the inner node, through its own slots or the stale path slot.

After this function returns, self.inner_node_ptr must not be used except through the returned SplitSide::Many, since the inner node was either reused for one side or deallocated. Each entry of left_children and right_children ends up on exactly one side.
