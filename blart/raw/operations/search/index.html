Module search 

Source
Expand description

Shared optimistic descent used by the trie operations.

Many of the trie operations (like lookup, insert, delete, finding range bounds) need to walk down to find an appropriate location based on an initial search key. This module has the shared logic for that initial walk.

The walk is “optimistic”, meaning that inner node prefixes which have implicit bytes are skipped without comparing them to the search key. Otherwise, for each prefix with implicit bytes, we’d need to recurse down to an abitrary leaf node to find out what those missing bytes actually are. This can slow down operations by a lot. Instead, the optimistic walk records the depth of the first skipped byte, and then once the walk terminates, it checks all the skipped bytes against a leaf. If the bytes match, then all good! Otherwise, we need to walk down from the root again to find the inner node where the mismatch actually happens.
