    left_child: Option<OpaqueNodePtr<K, V, PREFIX_LEN>>,
    right_child: Option<OpaqueNodePtr<K, V, PREFIX_LEN>>,
    elem: InnerNodePathElem<K, V, PREFIX_LEN>,
    alloc: &impl Allocator,
) -> (Option<OpaqueNodePtr<K, V, PREFIX_LEN>>, Option<OpaqueNodePtr<K, V, PREFIX_LEN>>)
Expand description

Split an inner node on the path, given the two halves of its child on the path.

left_child and right_child are the result of splitting the child on the path (the child at elem.pos.next_key_fragment), and either may be None if that side is empty. Returns the left and right halves of the inner node in elem, in the same form.

This works because every key under the path child has the same key byte at this inner node, so both halves of the path child keep that key byte. Every left sibling has a smaller key byte, so the left half goes after them. Every right sibling has a larger key byte, so the right half goes before them. After that, the inner node is split the same way as one with no child on the path, except that its slot for the path child is stale (see InnerNodePathElem::split).

§Safety

  • The caller must have exclusive access to the inner node of elem and every node reachable from it, and no other operation may read or write those nodes for the duration of this function.
  • Every node reachable from the inner node of elem, and every node in the subtrees of left_child and right_child, must have been allocated with alloc.
  • elem must satisfy the InnerNodePathElem invariants, and its inner node must have a child at elem.pos.next_key_fragment (the path child). That is, elem was pushed onto the path by collect_split_point_nodes, and its inner node has not been modified since.
  • left_child and right_child must be the result of splitting the path child. Each must point to a live node. They must be different nodes, and neither may be in elem.left_children or elem.right_children. Apart from the stale path slot in the inner node of elem, no node outside their own subtrees may point to them or to any node in their subtrees.
  • key_bytes must be the same key bytes that elem was collected with.

After this function returns, the inner node of elem must not be used except through the returned pointers, since it was either reused for one side or deallocated.
